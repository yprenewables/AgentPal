# AgentPal v0.3.5

正式版，发布日期：2026-10-26。

## 更新内容

- Central Node 提供的 Auth Profile 支持通过更多菜单中的 View details 查看详细信息。
- 复用本地 Profile 的详情弹窗，展示名称、auth.json 和 config-auth.toml，可选中和复制内容。
- Central Profile 的详情字段全部只读，不提供保存入口，保存函数增加只读拦截。

## 安装与生效

- macOS Apple Silicon：双击 `AgentPal-0.3.5-macos-arm64.dmg`，将窗口中的 AgentPal 拖入 Applications（应用程序），再从启动台或“应用程序”打开。更新时先退出旧客户端，拖入后选择“替换”；安装后推出安装磁盘。
- Windows x64：运行 `AgentPal-0.3.5-windows-x64.exe`。
- 更新前退出旧客户端，再打开新版本；已有配置和认证档案保留。
- 安装包发布于公司 YPShare 的 `AgentPal/v0.3.5` 目录，`latest` 指向该版本。
- 使用 `shasum -a 256 -c SHA256SUMS` 校验安装包。

## 验证范围

前端构建、模拟后端数据的浏览器交互检查（Central 详情只读且无保存入口、本地 Profile 可编辑）、Go 全量测试、go vet、macOS 和 Windows 构建、macOS 签名与版本信息、发布包 SHA-256 校验。Windows 为交叉编译产物，未在 Windows 实机验证。

macOS 改用 DMG 分发，内含同版本应用、Applications 快捷入口及中文安装说明；验证磁盘映像完整性、挂载内容、应用签名和发布包 SHA-256。
