# AgentPal v0.3.4

正式版，发布日期：2026-10-20。

## 更新内容

- Configuration Tab 仅支持从服务器到本地的 Skills 下载和更新。
- 仅展示服务器 Skills；新增或有差异的 Skills 可勾选下载，已一致的 Skills 不可勾选。
- 保留本地独有 Skills，移除 MCP 和删除操作。
- 后端拒绝删除、上传、MCP 及服务器清单外 Skill 请求，防止绕过页面限制。
- 下载更新完成后显示结果并刷新状态。
- 应用版本号、安装包名称及平台版本信息统一为 0.3.4，去除 beta 标签。

## 安装与生效

- macOS Apple Silicon：解压 `AgentPal-0.3.4-macos-arm64.zip`，将 AgentPal.app 拷贝到 Applications。
- Windows x64：运行 `AgentPal-0.3.4-windows-x64.exe`。
- 安装包发布于公司 YPShare 的 `AgentPal/v0.3.4` 目录，`latest` 指向该版本。
- 使用 `shasum -a 256 -c SHA256SUMS` 校验安装包。

Go 全量测试、竞态检查、go vet、前端构建、模拟后端数据的 Configuration 浏览器交互检查、macOS 签名和平台版本信息校验。Windows 为交叉编译产物，未在 Windows 实机验证。
