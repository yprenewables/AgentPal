# AgentPal v0.3.3-beta

## 更新内容

- Models 列表按模型显示名称升序排列，名称缺失时使用模型 ID，忽略大小写并采用数字自然排序（例如 GPT 2 在 GPT 10 之前）。
- 修复 models.json 中 supported_reasoning_levels 直接沿用接口倒序的问题，改为从轻到重排列，只保留模型支持的档位并去重。
- 排列顺序：none → minimal → low → medium → high → xhigh → max → ultra → persistent。
- 包含 v0.3.2-beta 的默认模型、推理强度按 Auth Profile 保存，以及 Raw / Pull / params / Save 紧凑工具栏。

## 安装与生效

- macOS Apple Silicon：解压 `AgentPal-0.3.3-beta-macos-arm64.zip`，将 AgentPal.app 拷贝到 Applications。
- Windows x64：运行 `AgentPal-0.3.3-beta-windows-x64.exe`。
- 已有 models.json：在 Models 页勾选 params 后点击 Save，重新生成推理档位顺序；完全退出并重新打开 Codex 后加载。
