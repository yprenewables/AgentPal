# AgentPal v0.3.1-beta

## 更新内容

- Authentication 页面在当前使用 API Key 时增加 **Log in with ChatGPT** 入口。调用本机 Codex CLI 打开浏览器授权，成功后自动保存并切换 ChatGPT Profile，保留原 API Key 档案。
- ChatGPT 登录支持取消和五分钟超时；在临时目录完成授权，失败不修改当前认证。
- `models.json` 按 Auth Profile 独立保存；切换时自动保存当前模型目录并恢复目标档案的模型目录及加载引用。
- 首次切换自动将已有模型目录归入当前档案；尚未配置模型的档案使用 Codex 默认目录。
- Central 同步和档案重命名保留本地模型配置；切换失败时恢复原认证、配置和模型文件。
- 支持 Codex 内置 OpenAI Provider，确保 ChatGPT 登录与 API Key 档案可往返切换。

## 下载与使用

- macOS Apple Silicon：下载 `AgentPal-0.3.1-beta-macos-arm64.zip`，解压后将 `AgentPal.app` 拷贝到 Applications。
- Windows x64：下载并运行 `AgentPal-0.3.1-beta-windows-x64.exe`。
- ChatGPT 登录需要本机已安装 Codex CLI。切换认证或模型目录后，请完全退出并重新打开 ChatGPT / Codex。
- 默认模型和推理强度继续使用现有全局设置。

## 验证范围

Go 全量测试、竞态检查、go vet、前端构建，以及 macOS 应用签名和产物哈希校验。浏览器已验证登录等待、取消及成功状态（模拟桌面桥接）；真实 ChatGPT 账号授权未执行。Windows 为交叉编译产物，未在 Windows 实机验证。
