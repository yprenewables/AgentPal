# AgentPal v0.3.2-beta

## 更新内容

- 默认模型和推理强度现在随 Auth Profile 独立保存，切换时与 models.json 一起恢复。
- 首次切换会自动将当前默认模型和推理强度归入当前档案；目标档案未设置时使用 Codex 默认值。
- 保存默认模型设置后立即写入当前 Profile；Central 同步、档案重命名和重复凭据合并保留本地设置。
- Models 工具栏改为紧凑的 **Raw / Pull / params / Save**，params 复选框紧跟 Pull，减少按钮换行。

## 下载与使用

- macOS Apple Silicon：下载 `AgentPal-0.3.2-beta-macos-arm64.zip`，解压后将 `AgentPal.app` 拷贝到 Applications。
- Windows x64：下载并运行 `AgentPal-0.3.2-beta-windows-x64.exe`。
- 切换认证或模型配置后，请完全退出并重新打开 ChatGPT / Codex。

## 验证范围

Go 全量测试、竞态检查、go vet、前端构建及 macOS 签名校验通过。浏览器验证了 980、720、680 像素宽度下工具栏排列和 Raw 编辑器交互（模拟桌面桥接）。Windows 为交叉编译产物，未在 Windows 实机验证。
